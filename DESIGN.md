# Тихий дом — Design System v3 «Quiet Depth»

Закон визуального слоя. Любое UI-изменение (человеком, Claude, Codex) аудируется
против этого файла. Если правка противоречит — правка неправа, не файл.

## Направление
Биг-тех операционный B2B (референс-ощущение: Linear, Mercury, Notion Calendar).
Серьёзный инструмент ежедневной работы похоронного агента: порядок, плотность,
тишина. Доверие через ясность. v3: премиум-глубина вместо плоскости — но
СДЕРЖАННАЯ (Linear/Mercury, не Revolut-глянец). Домен похоронный: объём через
мягкие слоистые тени и различимые поверхности, без gaudy-градиентов и блеска.

## Материал и глубина (v3)
Liquid Glass (web-приближение Apple): `.td-glass` / `.td-popover` / `.td-mobile-dock`.
Разрешён ТОЛЬКО на плавающем хроме — мобильная шапка, док, командная палитра,
поповеры, sheet-оверлеи. Fallback `prefers-reduced-transparency` обязателен.

Контентные карточки больше НЕ плоские: глубина через теневую шкалу (тень-кольцо
+ ambient + контактная + верхний блик `--hl-top`), не через жёсткую рамку.
5 слоёв поверхностей, каждый различим тоном или теневой высотой:
bg (поле) → surface (карточка) → elevated (raised/поповер) → interactive
(hover/инпут) → modal. Жёсткая рамка `border-line` на карточках устарела —
структуру держит тень-кольцо. Hairline остаётся для разделителей внутри.

## Тишина по умолчанию (закон плотности)
Платформа - инструмент на каждый день, глаз агента не должен сканировать россыпь
пилюль и микротекста. Правила:
- Строка списка = первичный факт (имя/название) + ОДНА строка «что дальше».
  Справа максимум один тихий факт (дата, этап) цветом ink-3.
- Бейдж/цветной лейбл - ТОЛЬКО исключение, требующее действия (просрочка,
  церемония < 48 ч, застой). Спокойное состояние молчит: ни чипа, ни точки.
- Прогресс-бары, степперы, «последняя активность» в строках списков запрещены -
  это ответ на вопрос, который агент не задавал.
- Один заголовок на блок. Дубль «номер этапа + кикер + h2» запрещён.
- Микротекст (< 12px) - только для исключений и денег, не для украшения строк.

## Пакет = пресет конструктора (доктрина сметы)
«Готовые решения» и «Собрать свой план» - не два мира, а две точки входа
в одни данные. Тариф продаёт (якорь цены, скорость), конструктор настраивает.
- Карусель тарифов: полный состав виден без клика, выбор = accent-обводка.
- «Изменить детали» раскладывает тариф на реальные позиции (lib/packagePresets.ts):
  поля формы + позиции каталога + строка «Организация и сопровождение»
  (остаток до точной цены тарифа). Сумма сходится копейка в копейку.
- После раскладки агент меняет гроб как обычную позицию; у итога живёт
  дельта от якоря: «+15 000 ₽ к тарифу» (warning) / «−15 000 ₽» (success).
- Отдельной функции «замена внутри пакета» не существует и не появится.

## Жёсткие запреты (анти-slop)
- НЕТ декоративных градиентов-заливок ради красоты. Градиент допустим только
  функционально (active-состояние nav, accent-панель) и едва заметный.
- НЕТ зерна/шумовых текстур, «бусин», орбов, glass-стэков на контенте.
- НЕТ серифных шрифтов. Один гротеск (Golos Text — гарнитура B2C tihiydom.com,
  общий шрифт связывает платформы). Заголовки = вес 650 + трекинг −0.02em.
- Тени — ТОЛЬКО из шкалы токенов (xs/soft/lift/pop/accent). Свои inline-тени
  с произвольными значениями = нарушение. Глубина дозированная, не «дутая».
- НЕТ em/en-тире в видимом тексте (только дефис).
- НЕТ декоративных точек/чёрточек/нумераций у заголовков и лейблов.
- НЕТ новых цветов вне токенов. Цвет — только акцент + семантика.

## Токены (globals.css @theme — единственный источник)
- Поверхности (5 слоёв): canvas/bg #eaeeea (глубже белого — белое всплывает),
  surface #ffffff, surface-elevated (=#fff + тень lift), surface-2/interactive
  #f3f5f2 (hover/инпут, светлее поля), surface-modal #fff.
- Paper #f6f5f3 (тёплая бумага tihiydom.com) — ТОЛЬКО клиентские экраны (/co),
  чтобы клиент с B2C-сайта видел тот же материал. В кабинете агента запрещён.
- Линии: hairline rgba(0,31,39,.10) / strong .18. Только разделители ВНУТРИ
  карточек; контур карточки держит тень-кольцо, не border.
- Текст: ink #001f27 / ink-2 #35535b / ink-3 #748d92.
- Акцент (active-система): evergreen #003a35 (hover #005149, soft #e4eee2). ОДИН.
- Семантика: success/warning/danger/info + *-soft (триада border+bg+text). Статусы.
- Gold #b4791f — исключительно денежные значения (суммы, комиссии).
- Радиусы (шкала): xs 8, sm 10, card 14, lg 18, xl 24, пилюли 999.
- Тени (шкала, слоистые): xs (волосок) · soft (карточка в покое: ring+ambient+
  contact) · lift (hover/raised) · pop (модалки) · accent (primary-кнопка). Плюс
  `--hl-top` = верхний inset-блик для премиум-объёма. Свои inline-тени запрещены.

## Типографика
- Строгая шкала-роли (utility-классы): `.t-display` → `.t-h1` → `.t-h2` →
  `.td-eyebrow` (section) → `.t-card-title` → `.t-body` → `.t-caption` → `.t-label`.
  Иерархия = вес + трекинг + цвет, не зоопарк кеглей. Полуступени запрещены.
- .td-display: sans 660, −0.025em, для H1/крупных значений.
- .td-eyebrow: 11px caps 0.12em, без декора. Максимум 1 на секцию.
- Числа/суммы/время: .tnum (tabular).

## Компоненты (классы — контракт, значения — этот файл)
- td-shell / td-entity-list: белая поверхность + shadow-soft (ring+ambient+блик),
  БЕЗ border. td-shell-elevated = raised (shadow-lift) для важных блоков.
- td-entity-row: hover = surface-2, active = scale 0.997. Левая 3px полоса — только статусная семантика.
- td-metric: surface + shadow-soft (карточка-метрика, не плоский прямоугольник).
- td-segmented/td-segment: серый трек, активный = белая пилюля + shadow-soft (iOS/Linear-паттерн).
- td-nav-orb: прозрачная плитка → hover surface-2 → active = accent заливка.
- td-side-nav-item: hover surface-2, active = тонкий градиент + тень (raised).
- td-rail: surface + border-right. td-dock/td-mobile-dock: glass + blur.
- icon-3d (имя историческое): плоская accent-soft плитка.
- Button: primary = accent + shadow-accent; secondary = surface + shadow-soft; ghost; danger.
- Badge/td-pill: hairline + soft-фон семантики + hl-top. Точка — только если статус.
- Конструктор сметы: паттерны wizard tihiydom.com (QuoteBuilder.module.css):
  radioCard (вариант + подпись простыми словами + цена справа), durationCard,
  routeChip (маршрут катафалка тёмными чипами), pkgFeatures (состав пакета буллетами).
  Выбор = accent-обводка + accent-soft заливка, не чёрный B2C.

## Моторика (Emil)
- Кривые: --ease-out .23,1,.32,1 · --ease-in-out · --ease-drawer .32,.72,0,1.
- Длительности: press 120ms · hover 150-180ms · dropdown/tab ≤200ms · sheet 360ms.
- Press: scale 0.97-0.98 на всех кнопках. Вход: rise 4-6px stagger ≤80ms.
- transition только с явными свойствами (никогда `all`). Только transform/opacity в анимациях.
- prefers-reduced-motion гасит всё (уже глобально).

## Слои
z: контент 1 · sticky chrome 40 · overlay/sheet 1000. Модалки/sheet — через createPortal
в body + inline position:fixed (unlayered body>* перебивает Tailwind-утилиты).

## Чек перед коммитом UI
1. Новые цвета/тени/радиусы вне токенов? → переделать.
2. Градиент/блик/текстура появились? → удалить.
3. Полуступень шрифта (13.5px)? → на шкалу.
4. transition: all? → явные свойства.
5. Серф/второй гротеск/эмодзи-иконка? → нет.
